# Store Inventory Frontend

This folder contains the static GitHub Pages website.

1. Push the contents of this folder to the `inventory` GitHub repository.
2. In GitHub, enable Pages from the `main` branch and `/ (root)`.
3. The app uses `https://store-inventory-backend-z07m.onrender.com/api/exec` for its backend.

The Render backend must be deployed and its `FRONTEND_ORIGINS` environment variable must include `https://mirnasir007.github.io`.
